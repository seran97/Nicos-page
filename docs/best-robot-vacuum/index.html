How long does the self-emptying base last before I need to empty it?

This model's base can hold up to 90 days of debris, so most single-pet households only empty the bag every 2-3 months.

Does LiDAR navigation actually make a difference?

Yes, LiDAR mapping is noticeably more accurate at avoiding furniture and creating clean room maps than cheaper bump-sensor robots.

With 6000Pa suction it transitions well between hardwood and low-to-medium pile carpet, though thick shag rugs may need a manual pass.

Most owners run the mop attachment 2-3 times a week for maintenance cleaning rather than daily deep mopping.

How loud is it on max suction?

On max power it's comparable to a standard upright vacuum, but most people run it on the quieter automatic mode.

FAQs

Is it safe to buy kids' running shoes on eBay?

Yes, provided you buy from a seller with a strong feedback history and check the size and condition details in the listing carefully.

Does the Clifton 10 kids' size run the same as adult sizing?

Youth (GS) sizing typically follows its own scale, so check the size conversion chart rather than assuming it matches adult numbers.

Is this shoe good for growing feet?

The Clifton's roomy toe box is generally well-suited to growing feet, though it's worth leaving a little extra room since kids grow fast.

Can these be used for school PE or sports?

Yes, they're lightweight and cushioned enough for general activity, PE class, and light running, though not designed as cleats or court shoes.

What if the size doesn't fit when it arrives?

Most eBay sellers accept returns on unworn shoes within a set window, so check the listing's specific return policy before buying.

Buying Guide: What To Look For

  1. Check the disc weight, not just the LED feature

    A properly weighted disc (around 175g) flies far more predictably than lightweight toy versions with lights slapped on.

  2. Confirm battery type and whether they're included

    Some light-up discs need batteries purchased separately — check the listing so you're not stuck without power on trip night.

  3. Prioritize durability if it's for outdoor/camping use

    Look for reviews mentioning drops, dirt, and repeated outdoor use if this is going in a camping or road trip gear bag.

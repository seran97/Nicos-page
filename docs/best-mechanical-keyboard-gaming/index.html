Frequently Asked Questions

What do 'magnetic switches' actually mean?
Hall-effect magnetic switches let you digitally adjust actuation distance instead of relying on fixed mechanical travel, which is what enables features like rapid trigger.
Is 8kHz polling noticeable in regular play?
Competitive players report it as a subtle but real reduction in perceived input lag, especially in fast-paced shooters.
Does the 60% layout include arrow keys?
No dedicated arrow keys — they're accessed via a function layer, which takes a few days of adjustment for most buyers.
